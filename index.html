TRE FASI.
UN VINCITORE.

Ogni trimestre un nuovo capitolo. Il ciclo e' semplice: crea, condividi, vota. Poi si ricomincia.

FASE 01

CREA IL TUO GIOCO

Scarica Level Engine, l'editor ufficiale della JAM. Un singolo file HTML con editor visuale a nodi, sprite system e minigame engine. Zero codice richiesto.

FASE 02

CARICA NELLA JAM

Quando il tuo gioco e' pronto, caricalo nella galleria del round attivo. Tutti i giochi caricati entro la scadenza partecipano alla selezione finale.

FASE 03

LA COMMUNITY VOTA

Gioca ai giochi degli altri partecipanti e assegna un voto da 1 a 10. A fine round, il gioco con il punteggio medio piu' alto vince la JAM.

Privacy Policy

Aggiornamento: Marzo 2026

Titolare del trattamento

Progetto personale open source — JAM Game Engine Monthly. Per comunicazioni: tramite la repo GitHub del progetto (apri una issue).

Dati personali raccolti

Non sono presenti form di registrazione, sistemi di login o newsletter. Nessun dato personale identificativo viene raccolto direttamente dal sito.

Archiviazione locale (localStorage / sessionStorage)

Il sito usa storage locale del browser per finalita' tecniche: le_ok (accettazione banner), voted_[id] (anti-doppio-voto), cc_consent (preferenze cookie con timestamp). Tutti eliminabili dal browser in qualsiasi momento. Base giuridica: necessita' contrattuale / interesse legittimo.

Google Fonts

Il sito carica font tipografici dal servizio Google Fonts (Google Ireland Ltd), risorsa tecnica essenziale all'interfaccia visiva. Questo comporta la trasmissione dell'indirizzo IP del visitatore a Google. Base giuridica: interesse legittimo (art. 6.1.f GDPR) per il corretto funzionamento dell'interfaccia. Google ha aggiornato il servizio Fonts nel 2022 per non conservare indirizzi IP in modo persistente. Alternativa: chi preferisce evitare questa trasmissione puo' auto-ospitare i font scaricandoli da fonts.google.com e sostituendo il tag link nell'HTML. Info: Privacy Google.

Pubblicita' (Google AdSense)

Previo tuo consenso esplicito, il sito mostra annunci tramite Google AdSense (Google Ireland Ltd, Gordon House, Barrow Street, Dublin 4, Irlanda). Google puo' usare cookie per annunci personalizzati e misurazione. Il trasferimento dati verso USA avviene tramite Standard Contractual Clauses. Base giuridica: consenso esplicito (art. 6.1.a GDPR). Revocabile in qualsiasi momento dalle Preferenze Cookie nel footer. Info: Privacy Google — Gestione annunci.

Fingerprint tecnico anti-abuso voti

Hash djb2 non reversibile generato da parametri pubblici del browser (risoluzione, lingua, fuso orario). Non identifica l'utente. Salvato in repo GitHub pubblica come stringa anonima. Base giuridica: interesse legittimo (art. 6.1.f GDPR) per integrita' del sistema di voto.

File caricati (giochi)

I file .html caricati vengono salvati su repo GitHub pubblica. Eseguiti nel browser tramite iframe con sandbox restrittivo (senza accesso allo storage del sito padre). Restano nella repo per tutta la durata del progetto. Rimozione: aprire issue su GitHub.

Hosting e terze parti

Netlify (USA) — puo' raccogliere log tecnici (IP, user-agent). Trasferimento dati extra-UE tramite SCC. Privacy Netlify.

GitHub (USA) — storage dei giochi e segnalazioni. Privacy GitHub.

Conservazione dei dati

Storage locale: senza scadenza fissa, eliminabile dal browser. Consenso cookie: 13 mesi. Giochi su GitHub: durata del progetto. Fingerprint voti: legati al gioco, rimossi con esso.

Diritti dell'utente (GDPR artt. 15-22)

Cosa utilizza questo sito

Questo sito usa storage locale tecnico (necessario, senza consenso) e cookie pubblicitari di terze parti (solo con consenso esplicito). Non usa cookie di tracciamento propri.

Storage locale tecnico (sempre attivo)

le_ok (localStorage) — registra che hai visto il banner informativo. Nessun dato personale.

voted_[id] (localStorage + sessionStorage) — impedisce di votare due volte. Valore: solo "1". Nessun dato personale.

cc_consent (localStorage) — salva le tue preferenze cookie con timestamp di data. Scade dopo 13 mesi.

Base giuridica: necessita' tecnica / interesse legittimo. Esenti da consenso ai sensi dell'art. 5.3 Direttiva ePrivacy 2002/58/CE e Linee Guida Garante italiano 10/06/2021.

Base giuridica: consenso esplicito (art. 6.1.a GDPR). Revocabile in qualsiasi momento dalle Preferenze Cookie nel footer senza conseguenze. Per maggiori info: Google Ads Privacy — Gestione preferenze annunci.
